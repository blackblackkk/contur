# Контур Главное — сайт агентства

Одностраничный сайт рекламного агентства полного цикла «Контур Главное».
Статичный, без сборщика и внешних зависимостей: HTML, CSS и ES-модули.

## Запуск

Нужен любой статический сервер (модули не работают по `file://`):

```bash
python3 -m http.server 8000
# затем открыть http://localhost:8000
```

Для публикации достаточно выложить содержимое репозитория на любой хостинг
статических сайтов. На GitHub Pages: Settings → Pages → Deploy from a branch → `main` / root.

## Структура

```
index.html          разметка всех разделов (читается и без JS)
css/tokens.css      цвета, шрифты, отступы, кривые анимации
css/base.css        сброс, кнопки, шапка, меню, курсор, форма, страница проекта
css/sections.css    шесть разделов: статичная раскладка + режим .motion
js/main.js          точка входа
js/config.js        контакты и настройки  ← заполнить перед запуском
js/content.js       услуги и проекты
js/brand.js         геометрия логотипа и производная графика
js/scroll.js        движок прокрутки (нативный скролл + сглаженные сцены)
js/figure.js        линия-фигура на canvas, js/stage.js — её «режиссёр»
js/intro.js         вступление с прорисовкой логотипа
js/hero.js, services.js, works.js, approach.js, why.js, contact.js — разделы
js/artwork.js       обложки демонстрационных концептов (SVG)
js/brief.js         форма заявки
js/nav.js, cursor.js, atmo.js, utils.js
assets/fonts        Inter и Inter Display (кириллица + латиница, лицензия OFL)
assets/brand        логотип, иконки, изображение для соцсетей
```

## Что нужно заполнить

**Контакты.** В `js/config.js` поля пустые — на сайте ничего не выдумано.
Укажите почту, телефон, Telegram или адрес: они появятся в разделе «Контакты»
и в форме заявки. Пока контактов нет, форма копирует текст заявки в буфер обмена.
Если задать `formEndpoint`, заявка будет отправляться POST-запросом в формате JSON.

**Проекты.** Сейчас в портфолио шесть демонстрационных концептов, и они так и подписаны.
Чтобы показать настоящие кейсы, замените записи в `js/content.js`, карточки в `index.html`
и обложки в `js/artwork.js` (вместо SVG можно поставить `<img loading="lazy">`).

**Логотип.** Вектор построен по присланному растровому файлу с сохранением пропорций.
Если есть исходный векторный файл, замените пути в объекте `LOGO` в `js/brand.js`
и файлы в `assets/brand` — шапка, вступление и подвал обновятся сами.

**Изображение для соцсетей.** В `index.html` у `og:image` относительный путь;
после публикации замените его на полный адрес сайта.

## Как устроена анимация

- Страница прокручивается нативно. Сцены читают сглаженное значение прокрутки
  и двигают только `transform`, `opacity` и `clip-path`.
- Класс `.motion` на `<html>` ставится, только если у посетителя не включено
  «уменьшение движения». Без него (и без JS) разделы идут обычным потоком:
  весь текст виден, галерея листается вбок, закреплённых сцен нет.
- Широкий экран: услуги и проекты закреплены, галерея едет по горизонтали
  от вертикальной прокрутки. Телефон: своя композиция первого экрана,
  свайп-лента проектов с привязкой, полноэкранное меню.
- Наклон 56,76° и скругления взяты из контура логотипа и повторяются
  в кнопках, переходах, масках и линии-фигуре.
